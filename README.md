# Gokah Website Portfolio

Responsive glassmorphism portfolio for Gokah Israel Ewoenam.

## Files
- `index.html` — portfolio structure and project links
- `style.css` — responsive glassmorphism design
- `app.js` — mobile menu, reveal animations and dynamic year
- `assets/` — supplied portfolio/project images

## Deploy
Upload the folder to GitHub and import the repository into Vercel.
No build step is required.
